## Recommended Tools for Generation:
- **DALL-E 3** (OpenAI) - Best for detailed prompts
- **Midjourney** - Best quality results
- **Adobe Firefly** - Good integration options
- **Ideogram AI** - Excellent for tech/modern aesthetics
- **Hugging Face Models** - Free option

## How to Use:
1. Copy each prompt above
2. Generate image using your preferred tool
3. Save as high-quality PNG/JPG
4. Name them: `01_hero.png`, `02_pose_detection.png`, etc.
5. Place in this `slide_images` folder

---

**Once generated, your images will be organized in:** `/frontend/public/slide_images/`
